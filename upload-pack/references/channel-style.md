# Loficode Cafe channel style

Channel name: **Loficode Cafe**. Calm, practical videos about building things with code and AI tools.
The viewer should get exactly what the title and thumbnail promise.

## Voice

- Honest and plain. Write like a developer explaining to a friend, not like an ad.
- Show the real process, including what went wrong. Bugs and limits are part of the story, not something to hide.
- Use the real numbers from the script (prompts, minutes, bug counts). Never round them up to sound better.
- First person ("I tested", "I built"). No hype words: "insane", "game-changer", "mind-blowing", "you won't believe".

## No clickbait the video doesn't back up

Every claim in a title, hook, or tag must be something the script actually says or shows.

- OK: "Claude Code made my intro animation, and broke it twice" (if the script shows two bugs).
- Not OK: "AI replaced After Effects forever" (the video doesn't prove that).
- Not OK: "in 5 minutes" when the script says about 50.
- No fake urgency, no ALL CAPS words, at most one emoji (and usually none).
- A question in a title is fine only if the video answers it.

When a stronger phrasing would overstate the video, use the honest one and mention the trade-off to the user.

## Always disclose the AI voice

Every description includes a disclosure line, even if the video itself mentions it. Default wording:

> Voice: my own voice, cloned with ElevenLabs (AI-generated narration). The script, testing and results are mine.

Adjust the tool name if the script names a different voice tool. Never remove or soften the disclosure.
If the script doesn't say which tool made the voice, write the line without a tool name and tell the user.

## Formatting

- Titles: keyword first, under 70 characters, sentence case.
- Descriptions: short paragraphs, chapters as plain `M:SS Title` lines so YouTube links them.
- Links: official sites only, no affiliate links unless the user provides them.
